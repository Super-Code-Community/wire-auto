# Транспорты и языковая независимость

## Концепт «связь» (link)

«Связь» (link) — это транспортный канал, по которому ядро общается со скриптом.
В v1 единственная реализованная связь: **`stdio`** (stdin/stdout процесса).

Каждая сторона объявляет, что умеет:
- Рантайм объявляет `transports` — что физически умеет водить.
- Ядро объявляет `links` — по каким связям говорит протокол.
- Скрипт объявляет `link` — какую связь использует.

Совместимость по связям проверяется на двух уровнях:
1. При **допуске ядра**: `core.links ∩ runtime.transports ≠ ∅`
2. При **рукопожатии**: `script.link ∈ core.links`

## Почему ядро языко-независимо

Ядро (`cores/regular`) не знает, на каком языке написан скрипт. Оно не встраивает
интерпретаторы и не анализирует поле `language` из `script.manifest`.

Ключевая идея: **ядро определяется транспортом (link), а не языком.**

Рантайм просто спавнит команду `cmd` из `script.manifest` и подключается к процессу
по объявленной связи. `cmd = ["python", "main.py"]` — это полностью дело скрипта;
ядро не смотрит, что там за бинарь.

Это означает:
- Bash-скрипт → `cmd = ["bash", "main.sh"]`
- Node.js-скрипт → `cmd = ["node", "main.js"]`
- Скомпилированный бинарь → `cmd = ["./main"]`

Всё работает одинаково — через тот же протокол JSON Lines по stdio.

## WIRE_SDK_DIR — единственный параметр окружения

При старте рантайм передаёт скрипту одну переменную окружения:

```
WIRE_SDK_DIR=<путь_к_папке_ядра>/sdk
```

Например, для `cores/regular`:
```
WIRE_SDK_DIR=/abs/path/to/cores/regular/sdk
```

Скрипт сам находит нужный шим под свой язык:
```
$WIRE_SDK_DIR/python/wire.py
$WIRE_SDK_DIR/bash/wire.sh      (будущее)
$WIRE_SDK_DIR/node/wire.js      (будущее)
```

## Тонкий шим

Шим — это ~30-100 строк, которые берут на себя весь протокол JSON Lines:
читают `hello`, шлют `ready`, предоставляют методы `log()` и `done()`.

Пример импорта шима в Python-скрипте:
```python
import os, sys
sys.path.insert(0, os.path.join(os.environ["WIRE_SDK_DIR"], "python"))
from wire import Script
```

Шим изолирует скрипт от деталей протокола. Скрипт работает с простым API:
```python
s = Script()
s.start()                      # читает hello, отвечает ready
s.log("сообщение")             # → {"type":"log","level":"info","message":"..."}
s.done(0)                      # → {"type":"done","exitCode":0}
```

## Масштабирование «N языков × M возможностей»

Без шима потребовалось бы встроить N интерпретаторов в ядро, умножив их на M
возможностей железа. Шимы решают это по-другому:

```
1 протокол  +  N шимов  +  M бриджей
```

Добавить новый язык = написать тонкий шим (~100 строк).
Добавить новую возможность железа = написать один бридж, доступный всем языкам сразу.

## Расположение шимов

Шимы живут рядом с ядром:

```
cores/regular/sdk/
└── python/
    ├── wire.py        шим (транспортный слой)
    └── wire_test.py   юнит-тест шима
```

Тест шима запускается напрямую интерпретатором:
```bash
python cores/regular/sdk/python/wire_test.py
```
