# Три манифеста — паспорта компонентов

Каждый уровень системы декларирует себя TOML-манифестом. Рантайм — тот, кто их
**сводит**. Принцип «у всего есть паспорт» — осознанный единый ментальный образ.

Файлы манифестов:
- `runtime/basic/runtime.manifest`
- `cores/regular/core.manifest`
- `scripts/examples/hello/script.manifest` (и любой другой скрипт)

## runtime.manifest

Описывает рантайм-модель: что умеет водить.

```toml
name = "wire-auto-runtime"
version = "0.1.0"
protocols = [1]          # версии протокола моста, которые рантайм поддерживает
transports = ["stdio"]   # транспорты (связи), которые рантайм умеет физически водить
cores = ["regular"]      # информационный список; НЕ является гейтом допуска
```

| Поле         | Тип       | Назначение                                      |
|--------------|-----------|-------------------------------------------------|
| `name`       | string    | человекочитаемое имя рантайма                   |
| `version`    | string    | версия рантайма (semver)                        |
| `protocols`  | []int     | поддерживаемые версии протокола моста            |
| `transports` | []string  | транспорты, которые рантайм умеет водить         |
| `cores`      | []string  | информационный список (не используется как гейт) |

> `cores` в `runtime.manifest` — **не гейт**. Источник истины — реестр допуска,
> который строится при старте сканированием `cores/*/core.manifest`.
> Подробнее — в [cores-and-runtimes.md](cores-and-runtimes.md).

## core.manifest

Описывает ядро: что предоставляет скриптам и что требует от рантайма.

```toml
name = "regular"
version = "0.1.0"
coreApi = 1              # версия контракта ядра (скрипты объявляют совместимость с ней)
protocol = 1             # версия протокола моста, на которой ядро говорит
provides = []            # возможности для скриптов (железо); в v1 пусто
links = ["stdio"]        # связи, по которым ядро говорит протокол
```

| Поле       | Тип       | Назначение                                          |
|------------|-----------|-----------------------------------------------------|
| `name`     | string    | имя ядра (скрипт ссылается по этому имени в `core`) |
| `version`  | string    | версия ядра                                         |
| `coreApi`  | int       | версия контракта ядра                               |
| `protocol` | int       | версия протокола моста                              |
| `provides` | []string  | предоставляемые возможности (capabilities)          |
| `links`    | []string  | поддерживаемые связи (транспорты)                   |

## script.manifest

Описывает скрипт: под что адаптирован и что ему нужно.

```toml
name = "hello"
version = "0.1.0"
core = "regular"         # на какое ядро нацелен (маршрутизация)
coreApi = 1              # версия контракта ядра, которую скрипт понимает
link = "stdio"           # по какой связи подключается
cmd = ["python", "main.py"]  # команда запуска (ядро не знает про языки)
language = "python"      # НЕОБЯЗАТЕЛЬНАЯ метка для клиента (не гейтит)
capabilities = []        # что запрашивает у железа; в v1 обязано быть пусто
```

| Поле           | Тип       | Обязательно | Назначение                                        |
|----------------|-----------|-------------|---------------------------------------------------|
| `name`         | string    | да          | имя скрипта                                       |
| `version`      | string    | да          | версия скрипта                                    |
| `core`         | string    | да          | целевое ядро (по имени из `core.manifest`)         |
| `coreApi`      | int       | да          | требуемая версия контракта ядра                   |
| `link`         | string    | да          | связь (должна входить в `core.links`)             |
| `cmd`          | []string  | да          | команда для запуска скрипта                       |
| `language`     | string    | **нет**     | информационная метка языка (только для клиента)   |
| `capabilities` | []string  | да          | запрашиваемые возможности (в v1 всегда `[]`)      |

> Поле `language` — **необязательная клиентская метка**. Ядро её не читает и не
> принимает никаких решений на основе `language`. Ядро язык-агностично по дизайну.
> Подробнее — в [transports-and-language-independence.md](transports-and-language-independence.md).

## Связь между манифестами

При каждом запуске рантайм сводит все три манифеста в порядке проверок.
Подробнее — в [handshake.md](handshake.md).
