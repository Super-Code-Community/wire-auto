# Граница app↔core: двусторонний мост

Граница **app↔core** — точка, в которой клиентское приложение общается с бандлом ядра.
Клиент и бандл живут в разных процессах; между ними — долгоживущий канал поверх
stdio, по которому идут JSON Lines.

```
клиент (apps/…)
      │  stdin  ──── команды ───▶  cores/regular/cmd/core
      │  stdout ◀─── события ────  cores/regular/cmd/core
      └─────────────────────────────────────────────────
```

Один процесс `core` обслуживает всю сессию: несколько запусков подряд, не
перезапускаясь между ними. Клиент завершает сессию командой `exit`.

## Команды (app → core, stdin)

| Поле `type` | Доп. поля | Назначение |
|-------------|-----------|------------|
| `list`   | — | Запросить каталог доступных скриптов |
| `run`    | `dir` (путь к папке скрипта) | Запустить скрипт |
| `cancel` | — | Отменить текущий прогон |
| `exit`   | — | Завершить мост |

Пример команды:
```json
{"type":"run","dir":"scripts/examples/hello"}
```

## События (core → app, stdout)

| Поле `type` | Поля события | Когда приходит |
|-------------|-------------|----------------|
| `catalog` | `scripts[]` — массив объектов `{name, dir, language, version, capabilities}` | Ответ на `list` |
| `ready`   | — | Скрипт запущен и начал выполнение |
| `log`     | `level`, `message` | Сообщение от скрипта во время выполнения |
| `result`  | `status`, `exitCode`, `errorCode`\*, `errorMessage`\*, `result`\* | Скрипт завершился (OK или ошибка) |
| `error`   | `message` | Фатальная ошибка моста (например, скрипт не найден) |

\* — поля присутствуют, только если непусты.

Поле `status` в `result`:

| Значение | Смысл |
|----------|-------|
| `OK`     | Успешное завершение |
| `CANCELLED` | Прогон отменён командой `cancel` |
| `HANDSHAKE_FAILED` | Конфликт манифестов; см. `errorCode` |
| `SCRIPT_FAILED` | Скрипт упал или вернул ненулевой `exitCode` |

## Пример диалога

```
app  → {"type":"list"}
core → {"type":"catalog","scripts":[{"name":"hello","dir":"scripts/examples/hello","language":"python","version":"3","capabilities":[]}]}

app  → {"type":"run","dir":"scripts/examples/hello"}
core → {"type":"ready"}
core → {"type":"log","level":"info","message":"hello from python"}
core → {"type":"result","status":"OK","exitCode":0}

app  → {"type":"exit"}
```

## Стриминг необязателен

Бандл ядра может вернуть данные двумя способами:

1. **Потоковое ядро** — поэтапно: несколько событий `log`, потом `result`.
2. **Ядро разом** — данные готовы сразу: единственный `result` с полем `result`
   (JSON-пейлоад), без предшествующих `log`.

Для клиента форма одна: последовательность событий, заканчивающаяся `result`
(или `error`). Наличие промежуточных `log` определяет ядро, а не протокол.

Подробнее о бандлах ядер — в [cores.md](cores.md).
